# 수학적 계약, 성립 조건과 반례

이 문서는 구현을 읽기 위한 명세다. 새 정리를 일반 자연어 문제 전체에 증명했다는 주장이 아니다. 표준적인 최적화·정보·프로그램 분석 개념을 연구 문제에 적용한 것이며 [관련 문헌](REFERENCES.md)을 함께 참고한다.

## 1. 추가 coverage와 추정 오차

질문 q의 사실 집합을 F, 사실 중요도를 w_f ≥ 0, 후보 i의 coverage를 a_if ∈ [0,1], 보호 맥락 P의 coverage를 b_f라 두자.

```text
G_q(S | P) = Σ_f w_f [max(b_f, max_{i∈S} a_if) − b_f]
J_λ(S)     = G_q(S | P) − λ C(S)
```

각 사실의 max-coverage는 단조이고 한계 이익이 감소한다. 비음수 가중합도 그렇다. 하지만 실제 답변 효용이 이 형태라는 가정은 별개다. 독립 균등 비트 A, B에 대해 Y=A XOR B이면 `I(Y;A)=I(Y;B)=0`, `I(Y;A,B)=1`이다. 하나의 필수 관계를 여러 문장이 함께 완성할 수 있다.

공통 비용도 따로 보아야 한다. 각 항목의 이익 0.6, 내용 비용 0.1, 한 번만 드는 공통 비용 0.9라면 단일 항목의 순이익은 −0.4, 두 항목은 +0.1이다. 양의 단일 한계 이익만 취하는 greedy는 빈 집합에서 멈춘다. max-coverage의 부분모듈러성을 전체 목적함수나 제약 문제의 greedy 보장으로 옮기지 않는다.

추정 점수가 모든 후보에서 `|J_hat(S)−J(S)| ≤ ε`라 하자. 실제 최적해 S*, 추정 최적해 S_hat에 대해 다음처럼 분해된다.

```text
J(S*) − J(S_hat)
 = [J(S*) − J_hat(S*)]
 + [J_hat(S*) − J_hat(S_hat)]
 + [J_hat(S_hat) − J(S_hat)] ≤ 2ε
```

가운데 항은 추정 최적성으로 0 이하이다. 자연어에서 균일 오차 ε를 아는지, 또는 상계할 수 있는지가 실용적 난점이다. Phase 01은 ε를 계산할 수 있는 합성 세계에서만 이를 확인했다.

λ1 < λ2의 정확한 최적해를 S1, S2라 하고 두 최적성 부등식을 더하면 `(λ2−λ1)(C(S1)−C(S2)) ≥ 0`이다. 따라서 고정 후보·고정 점수·고정 비용에서는 가격을 올릴수록 최적 비용이 증가하지 않는다. 모델 재평가나 후보 생성이 변하면 이 가정은 성립하지 않을 수 있다.

## 2. 선택적 압축의 위험 상한

고정 후보 정책 M개 중 정책 i가 수락한 n개 사례에서 k개 오류가 있었다고 하자. 한쪽 정확 이항 상한 U는 다음 식의 해다. `k=n`이면 U=1이다.

```text
Σ_{j=0..k} binom(n,j) U^j (1−U)^(n−j) = δ/M
```

오류가 0이면 `U = 1 − (δ/M)^(1/n)`이다. `U≤α`를 요구할 때 필요한 n은 다음과 같다.

```text
n ≥ ceil(log(δ/M) / log(1−α))
```

M=22, δ=.05에서 α=.05이면 119, α=.01이면 606이다. 독립 표본·고정 정책군·보정과 선택의 적절한 분리 등 통계 조건이 중요하다. 결과를 본 후 추가한 양방향 연결 진단은 이 22개 정책의 보정 보장을 상속하지 않는다. 평균 위험 제약은 모든 질문 유형별 위험 제약과 다르다.

## 3. 질문에 충분한 증거

Ω는 가능한 세계 집합, h는 실제 세계, q는 질문, A_q(h)는 그 답이다. 증거 E와 양립하는 세계를 Ω(E)라 하자. 선택한 원문과 참 메타데이터만이 증거이며, 선택 마스크를 비밀 답 전달 채널로 사용하지 않는다.

```text
Sufficient(E,q)  ⇔  |{ A_q(w) : w∈Ω(E) }| = 1
B*(h,q)         =  min C(E), subject to Sufficient(E,q)
```

답이 여러 개인 경우 ambiguity나 더 많은 정보가 정상적인 결과다. 이용 가능한 모든 관측이 같지만 답이 다른 세계가 둘 존재하면, 단일 확정 답이라는 계약의 B*는 무한대일 수 있다. 토큰을 더 주는 것만으로 없는 정보를 만들 수 없다.

동일 후보·비용·실제 세계를 두고 대안 세계의 집합이 커지면 만족해야 할 조건이 늘어나므로 최소 충분 비용은 감소하지 않는다. 지원해야 할 질문 집합을 늘려도 최소 비용은 감소하지 않는다. 반면 참 인덱스를 **선택적으로** 사용할 수 있게 하면 후보를 추가하는 것이므로 최적 비용은 증가하지 않는다. 인덱스가 거짓이면 이 보장에 필요한 전제가 깨진다.

### 반사실 제거와 집합 덮개

현재 답과 다른 답을 주는 세계들을 W라 하고, 출처 i와 양립하지 않는 W의 부분집합을 D_i라 하자. 고정된 참 메타데이터를 조건으로 다음이 성립한다.

```text
Sufficient(S,q) ⇔ union_{i∈S} D_i = W
```

각 출처가 제거하는 반사실을 모두 덮는 최소 비용 선택이므로 가중 집합 덮개 형태다. `|union D_i|`는 단조 부분모듈러지만, **모든 반사실을 제거했는지의 불연속 판정**이나 실제 LLM 답변 효용을 같은 성질로 간주하지 않는다. Phase 04는 5개 출처라 전수 탐색했고 greedy 근사 성능을 주장하지 않았다.

### 정보 하한의 해석

서로 다른 답 동치류가 K개이면 그것을 항상 구분하는 고정 길이 이진 답 부호는 최소 `ceil(log2 K)`비트가 필요하다. Phase 04에서는 현재·과정·원문·공동 질문이 각각 K=6,26,4,52여서 3,5,2,6비트다. 이 값은 자연어 프롬프트 최소 토큰 수가 아니다. 질문, 사전 공유 의미, 원문 출처, 인덱스, 모델 오류와 복호화 비용이 모두 다른 문제다.

## 4. 보수적 추상 의미와 역방향 의존성

구체 상태는 각 모임의 시간·장소 값이다. 추상 상태는 필드마다 가능한 값의 집합 또는 TOP이다. 구체 상태 집합을 나타내는 함수 γ를 쓰면, 사건 i의 의미 근사에 필요한 조건은 다음이다.

```text
F_i(γ(a)) ⊆ γ(F_i#(a))
```

즉 추상 실행은 가능한 실제 상태를 빠뜨리지 않아야 한다. 이 조건을 사건마다 만족하면 합성에도 포함 관계가 유지된다. 이는 **파싱한 사건이 실제 문장 의미를 포함한다는 조건** 위에서 성립한다. 정규식이 인식했다는 사실만으로 자유 자연어의 의미를 검증한 것은 아니다.

절대 지정은 해당 필드의 이전 값 의존성을 제거한다. 상대 이동은 그 값을 읽으므로 의존성을 남긴다. A←B는 그 역사적 위치의 B를 요구한다. 모호한 갱신은 가능성을 합쳐 남기고, 미해석은 모든 필드를 영향권에 둔다. 질문의 필요 집합을 역방향으로 전달하면서 영향 없는 사건을 생략한다.

추상 값의 singleton은 모형 내의 단일 답을 의미한다. product domain은 필드 사이 상관관계를 잃을 수 있어서 답이 유일한 실제 경우에도 보류할 수 있다. 반대로 해석 자체가 틀리면 singleton이어도 틀린 단정이 가능하다. `drop_unknown`의 실패가 그 위험을 직접 보여준다.

구체 투영 보존 감사와 추상 soundness는 구분한다. 전자는 정해진 작은 연산 공간을 구체 실행하여 비교한 결과이고, 후자는 의미 근사가 실제 전이를 포함한다는 가정을 요구하는 일반적인 추론이다. 유한 감사가 모든 자유 한국어 의미를 증명하지 않는다.

## 5. 정수 변경 구간의 정확한 최소 비용

한 필드에 대한 m개 정수 이동 d_i와 원문 비용 c_i>0가 있다. 다른 사건이 이 필드를 읽거나 쓰지 않는 구간에서, 최종 상태만 묻는다면 원래 총합 t를 보존하는 최소 비용 부분집합을 찾을 수 있다.

```text
t = Σ_i d_i
D_0(0)=0, D_0(s≠0)=∞
D_i(s) = min(D_{i−1}(s), D_{i−1}(s−d_i)+c_i)
answer = D_m(t)
```

포함·미포함의 두 경우가 모든 부분집합을 나누므로 귀납적으로 정확하다. 구현은 signed reachable sum 사전을 사용하고 같은 비용이면 출처 인덱스 tuple로 결정적으로 tie-break한다.

R을 reachable sum의 최대 개수라 하면 상태 갱신 수는 O(mR)이고 `R≤2Σ|d_i|+1`이다. 수치 크기에 의존하므로 의사다항 시간이다. 실제 Python 구현은 선택 경로 tuple을 복사하므로 그 비용이 추가된다. 시간은 일반 정수이며 24시간 modulo나 실제 달력 제약을 모델링하지 않는다.

정확성의 범위는 제한된 구간의 원문 부분집합이다. 중간 copy-read가 있거나, 변경 과정·원문 인용을 묻거나, 부수 효과가 있다면 최종 합만 보존해서는 안 된다. 문장을 새로운 요약으로 생성하는 비용 문제도 다루지 않는다.

## 6. 비용과 증거의 분리

```text
실제 총비용의 후보 = 최종 프롬프트 + 검색 + 해석 + 검증 + 응답 생성 + 고정 호출비
현재 측정한 proxy = 최종 렌더링 UTF-8 bytes + 상세 파서에 전달한 원문 bytes
```

후자는 전자의 일부를 단순한 단위로 모형화한 것이다. 상세 파서는 로컬 Python 함수다. 호출 수가 줄었다고 실제 LLM 호출비나 지연이 같은 비율로 줄었다고 할 수 없다. snapshot SHA 검사는 전체 원문을 읽고, 내부 일관성은 최신성·진실성·권한을 증명하지 않는다.
