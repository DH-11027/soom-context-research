# Phase 06 실행 전 계획 — 범위만 아는 미해석 사건

작성: 2026-10-22 09:27 UTC (18:27 KST). 기준 커밋:
`780891f6c147cfd3c1a3b0d065792776aaa525f3`.
이 계획은 새 선택기 구현 및 새 평가 실행 전에 작성했다. 기존 연구를 읽고 선택한
방향이므로 과거 자료에 대한 사전 등록이 아니다. 코드·개발 자료의 최종 동결은
별도 `freeze.json`에 남기고, 그 이후 새 holdout을 처음 읽고 실행한다.

## 한 가지 병목과 가설

모르는 문장을 전역 TOP으로 처리하는 데서 발생하는 답변 범위 손실에 집중한다.
정확한 새 값을 해석하는 문법 확장이 아니라 **may-write 상한만 얻는 분석**을 시험한다.

- H6-S: 원문 전체와 일치하는 제한 문법에서 영향 필드 상한 W를 얻고, 그 필드만
  TOP으로 보내면, 질문의 추상 답 포함 관계를 지키면서 전역 TOP보다 더 많은
  질문을 인증하고 더 짧은 원문 선택을 만들 수 있다.
- H6-C: 출력 절감과 상세 파싱 감소가 계약 추출·추가 역방향 탐색 비용을 상쇄한다.
  이것은 별도의 경험 가설이다. H6-S가 참이어도 H6-C는 기각될 수 있다.

인용, 부정, 복합 변경, 별칭을 표면 단어만으로 처리하지 않는다. 정해진 전체
문법에 맞지 않으면 전역 TOP이다. 이 언어 가정은 자유 한국어의 증명이 아니다.
새 `must_overwrite`나 `may_read`를 자연어에서 추정하지 않는다. 알려진 기존
set/add/copy/maybe_set 의미는 그대로 사용하고, 미해석 W의 값을 TOP으로 넓힌다.
`D <- D \\ W`는 실제 사건이 반드시 덮어쓴다는 주장이 아니라 **추상 TOP
변환의 이전 값 의존성이 사라진다**는 뜻이다. 자세한 계약은 `THEORY.md`에 둔다.

## 입력·출력과 비교군

입력: 완전한 순서/opaque ID/원문, 공개 엔터티 목록, 질문, snapshot head/digest.
원문 분석기에 gold, family, split, 정답 값, 정답 관계를 전달하지 않는다.
출력: 원문 선택, 제한 모형의 가능한 값 또는 TOP, 인증/모호성/fallback/미지원,
계약 추적, 비용 벡터. 계획 상태만 다루며 실제 실행·미완료 부탁·권한을 인증하지 않는다.

1. `full_history`: 해시 검증 후 전체 원문 전달. 답변 생성기는 아니다.
2. `frozen_lazy`: 수정하지 않은 Phase05 revision02 엔진.
3. `global_control`: 같은 새 계약 분석 비용을 지불하지만 W를 전역으로 넓히는
   ablation. 최종 의미·선택이 frozen_lazy와 일치해야 한다.
4. `text_scoped`: 원문 계약만 이용하는 새 선택기.
5. `text_scoped_eager`: 같은 계약/상세 문법을 전체 이력에 eager 적용. 새 lazy와
   의미·선택 동등성을 검사한다. 이 비교는 호출 위치의 효과다.
6. `oracle_scoped`: 기존 파서가 모르는 문장에 **gold may-write만** 받는다.
   정답 값·정답 AST를 실행하는 파서가 아니다. footprint-only 계열의 제한된 기준이다.

상쇄 reducer는 주실험에서 끈다. 두 개선을 섞지 않는다. 기존 05r2 재현에서
기존 algebraic/DP/비공허성 suite가 그대로 통과하는지 확인한다. 새 scoped 언어와
reducer의 상호작용은 이번 가설 밖이며 미실행으로 보고한다.

## 사전에 정한 판정과 비용

지원 질문의 요구 필드는 평가기에서 별도로 정의한다. prediction 키 전체 일치,
인증 시 모든 필드 singleton, 정답 joint 집합의 product 예측 포함을 검사한다.
빈 인증, 누락 필드, 틀린 값, 거짓 unsupported를 평가기 mutation으로 주입한다.

보고할 분모/지표:

- false certification / certified / all; containment 위반 / supported.
- gold singleton supported 중 인증 회수율, 실제 모호성과 분석 모호성.
- opaque fallback, unsupported, 실제 전체 이력 출력 비율.
- 계약 발동 수, 실제 원문/출력 축소 건수. 보존 검사만 통과하면 성공으로 삼지 않는다.
- 출력 UTF-8 bytes; cheap/contract/detail/reparse 호출·원문 bytes;
  해시 직렬화 bytes; 방문 기록 수; 추상 검증 단계 수; 로컬 실행 시간.
- `output + hash + cheap + contract + detail + reparse source bytes`는 각 byte에
  동일 가중치를 준 명시적인 **작업량 proxy**로만 보고한다. 비용 벡터가 우선이며
  CPU·LLM 토큰·금액으로 환산하지 않는다. 실험 평가기 비용은 별도 실행 시간이다.
- 로컬 시간은 동일 corpus/환경, 순서 회전, 반복 측정의 중앙값/범위를 남긴다.
  정규식 파서 실험이며 LLM 지연 측정이 아니다.

안전성 반례가 한 건이라도 나오면 보장 주장을 철회하고 실패를 그대로 저장한다.
holdout을 본 뒤 코드/라벨을 수정하면 새 revision과 사후 결과로 구분한다.
평균 효과뿐 아니라 유형별 악화·전역 TOP 유지·추가 비용을 보고한다.
