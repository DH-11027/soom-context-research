# SOOM Context Research

**질문에 필요한 근거를 보존하면서 대화 맥락을 줄일 수 있는가?**

SOOM의 긴 대화 프롬프트 문제에서 시작해, 가중 정보 선택 → 변경 관계 추적 → 질문별 충분성 → 역방향 의미 분석으로 진행한 연구 기록이다. 2026-10-22까지의 다섯 단계, 실패한 실험, 수정 이력, Python 코드, 전체 합성 데이터와 결과를 함께 보관한다. Codex와 웹 ChatGPT가 번갈아 연구를 이어가기 위한 저장소다.

**현재 상태: 연구용 프로토타입. 운영 적용 없음.** 실제 LLM 답변 품질, 토큰 수, 운영 지연은 아직 측정하지 않았다. 아래 절감률은 각 실험에서 정의한 UTF-8 바이트 비용이며 전체 프롬프트 토큰 절감률이 아니다.

## 연구가 도달한 지점

문장의 유사도는 답에 필요한 근거인지와 다르다. “지금 몇 시야?”에는 마지막 확정 시간만 필요할 수 있지만, 상대 변경에는 이전 값이 필요하고, “어떻게 바뀌었지?”에는 변경 이력 자체가 필요하다. 따라서 질문에서 출발해 필요한 상태와 의존성을 역으로 추적하고, 해석하지 못한 문장을 조용히 버리지 않는 방향이 가장 유망했다.

| 단계 | 검증한 것 | 핵심 관측 | 남은 한계 |
|---|---|---|---|
| 01 | 가중 coverage와 정확한 조합 최적화 | 최적화가 정확해도 의미 점수의 오차가 선택을 망칠 수 있음 | 의미 점수는 가정한 값 |
| 02 | 근거 보존·참조 연결·통계적 선택 보류 | 어휘 선택 46/512 실패; 정답 연결을 준 진단에서는 0/512 | 정답 연결은 자동 추출한 것이 아님; 22개 보정 후보 모두 미채택 |
| 03 | 원문만 입력받는 관계 추출 | 후보를 보존해도 스트레스 조건에서 근거 누락; 평가 라벨도 사후 교정 | 같은 저자가 만든 합성 문장; 교정된 0/288은 새 독립 시험이 아님 |
| 04 | 유한 세계에서 질문별 최소 충분 근거 | 현재 상태 질문 비용 282.28 → 177.24 bytes, 공동 질문 대비 37.21% 감소 | 가능한 세계와 참 인덱스를 아는 oracle 실험 |
| 05 | 역방향 의존성 + 필요한 문장만 상세 해석 | **main 384질문**에서 출력 63.13% 감소; 상세 해석 3,140 → 224회 | stress 288질문에서는 출력 감소 9.21%, 인증 범위 12.5% |
| 05 revision02 | 관측되지 않는 정수 변경 구간의 최소 비용 부분집합 | 43,923개 투영 비교 보존; 2,936개에서 추가 축소; 합계 2.42% 추가 감소 | 기존 672질문에서는 추가 축소 0건, 재해석 비용 발생 |

Phase 05 전체는 **336개 이력 × 질문 2개 = 672질문**이다. 같은 이력의 질문과 같은 템플릿 변형은 독립 표본으로 세지 않는다. `certified_model`은 제한된 의미 모형 아래의 단일 답 판정이며 자연어 사실성 인증이 아니다. [정확한 분모와 실패 조건](docs/RESEARCH_LOG.md)을 함께 읽어야 한다.

## 코드 실행

Python 3.12 표준 라이브러리만 사용한다. 모델 API, API 키, 데이터베이스, 외부 Python 패키지가 필요 없다.

```bash
python tools/verify_archive.py
python tools/reproduce.py --phase all
```

재현기는 `.reproductions/`의 새 복사본에서 실행한다. 원래 결과를 덮어쓰지 않고, 재생성한 JSON의 실험 내용이 보관 결과와 일치하는지 비교한다. 시간·Python 버전 등 비교 제외 항목은 [재현 문서](docs/REPRODUCIBILITY.md)에 한정해서 명시한다.

원래 보고서는 다운로드 후 [research/index.html](research/index.html)을 브라우저로 열면 읽을 수 있다. GitHub에서 HTML 파일 링크는 소스로 표시될 수 있다. GitHub 안에서는 위 Markdown 문서와 각 단계의 `research.ipynb`를 읽는 편이 편하다. 노트북은 설명과 실행 예제를 담은 미실행 문서이며, 보관 JSON은 CLI 실험의 결과다.

## 저장소 구성과 보존 원칙

```text
HANDOFF.md                  다음 연구자를 위한 현재 상태
docs/                       전체 과정, 수학, 한계, 다음 실험
tools/                      읽기 전용 무결성 검사와 복사본 재현기
archive-manifest.json        보관 파일 59개의 SHA-256
research/                   2026-10-22 연구 파일의 바이트 그대로 복사본
  experiment.py             Phase 01
  phase02/ ... phase05/     이후 실험
  phase05/revision02/       실제 관측한 파서 결함의 수정 실험
```

원본 결과가 잘못 해석될 여지가 있어도 삭제하거나 유리한 결과로 바꾸지 않았다. 특히 Phase 03 라벨 수정과 Phase 05의 `앞으로` 파싱 결함은 별도 기록으로 보존했다. 새 연구는 새로운 폴더에서 진행하고 기존 프로토콜을 다시 동결하지 않는다.

이 저장소에는 합성 연구 자료만 포함한다. 개인 대화 원문, SOOM 운영 코드·설정·DB, 첨부 사진은 포함하지 않는다. 공개 논문은 링크로 인용하며 논문 본문이나 외부 벤치마크 데이터는 재배포하지 않는다.
